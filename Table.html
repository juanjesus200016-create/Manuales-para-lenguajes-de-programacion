2. Comandos HTML

Qué Cómo se escribe Qué hace Dónde se coloca
Estructura <!DOCTYPE html> Declara HTML5 Primera línea
Raíz <html lang="es"> Contiene el documento Después del doctype
Cabeza <head> Metadatos invisibles Dentro de html
Cuerpo <body> Contenido visible Dentro de html
Título <h1>...</h1> Jerarquía de títulos h1-h6 Dentro de body
Párrafo <p>texto</p> Bloque de texto Dentro de body
Enlace <a href="url">texto</a> Hipervínculo Dentro de body
Imagen <img src="x.jpg" alt="desc"> Muestra imagen Dentro de body
Lista <ul><li>x</li></ul> Lista con viñetas Dentro de body
Div <div>...</div> Contenedor en bloque Dentro de body
Span <span>...</span> Contenedor en línea Dentro de texto
Formulario <form action="x.php" method="POST"> Envía datos al servidor Dentro de body
Input <input type="text" name="x"> Campo de entrada Dentro de form
Botón <button type="submit">Enviar</button> Botón clicable Dentro de form
Script <script src="x.js"></script> Incluye JavaScript Body o head
Estilo <link rel="stylesheet" href="x.css"> Vincula CSS externo Dentro de head
Comentario <!-- texto --> Comentario invisible Cualquier lugar

4. Comandos JavaScript

Constante const libro = "HTML"; Referencia fija reutilizable Antes de usarla

Seleccionar document.querySelector("#id"); Busca en el DOM Después de cargar HTML

Recibir GET $_GET["id"] Datos de URL En cualquier PHP

Escapar htmlspecialchars($texto) Evita XSS Al imprimir

Foreach foreach ($arr as $x) { ... } Recorre array Dentro de función
