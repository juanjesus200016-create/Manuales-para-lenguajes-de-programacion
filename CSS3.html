Capítulo 14 — Diseño responsive

14.1 — Media queries

@media (max-width: 768px) {
    body { font-size: 14px; }
    .menu { display: none; }
}

Breakpoints comunes

DispositivoAncho típico
Móvilhasta 480px
Tablet481px – 768px
Portátil769px – 1024px
Escritorio1025px en adelante

Enfoque mobile-first (recomendado)

/* Base para móvil */
body { font-size: 14px; }

/* Mejoras para pantallas grandes */
@media (min-width: 769px) {
    body { font-size: 16px; }
}

14.2 — Imágenes responsive

img {
    max-width: 100%;
    height: auto;
}

14.3 — Unidades fluidas

h1 { font-size: clamp(1.5rem, 4vw, 3rem); }

clamp(mínimo, preferido, máximo) ajusta automáticamente.

Capítulo 15 — Buenas prácticas

  1. Reset básico: * { box-sizing: border-box; margin: 0; padding: 0; }
  2. Organiza el CSS por secciones.
  3. Usa variables CSS
  4. Evita !important
  5. Prefiere clases sobre IDs.
  6. Mobile-first
  7. Usa rem para texto.
  8. Valida tu CSS en jigsaw.w3.org/css-validator
