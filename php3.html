Capítulo 18 — Manejo de archivos

18.1 — Leer un archivo completo

<?php
$contenido = file_get_contents("datos.txt");
echo $contenido;
?>

18.2 — Leer línea por línea

<?php
$archivo = fopen("datos.txt", "r");

while (($linea = fgets($archivo)) !== false) {
    echo $linea . "<br>";
}

fclose($archivo);
?>

18.3 — Escribir en un archivo

<?php
// Sobrescribe (borra el contenido anterior)
file_put_contents("log.txt", "Nueva entrada\n");

// Añadir al final
file_put_contents("log.txt", "Otra entrada\n", FILE_APPEND);
?>

18.4 — Modos de apertura

ModoSignificado
rSolo lectura (debe existir)
wEscritura (borra si existe, crea si no)
aAñadir al final (crea si no existe)
r+Lectura y escritura
xCrear nuevo (falla si existe)

18.5 — Comprobar si un archivo existe

<?php
if (file_exists("datos.txt")) {
    echo "El archivo existe";
}

// Tamaño en bytes
echo filesize("datos.txt");

// Borrar
unlink("datos.txt");

// Copiar
copy("origen.txt", "destino.txt");

// Renombrar o mover
rename("viejo.txt", "nuevo.txt");
?>

Capítulo 19 — Subida de archivos

19.1 — Formulario HTML

<form action="subir.php" method="POST" enctype="multipart/form-data">
    <input type="file" name="archivo">
    <button type="submit">Subir</button>
</form>
⚠️ Clave: el atributo enctype="multipart/form-data" es obligatorio para subir archivos. Sin él, no funciona.

19.2 — Procesar en PHP

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $archivo = $_FILES["archivo"];
    
    // Verificar errores
    if ($archivo["error"] !== UPLOAD_ERR_OK) {
        die("Error al subir el archivo");
    }
    
    // Datos del archivo
    $nombreTemp = $archivo["tmp_name"];
    $nombreOriginal = basename($archivo["name"]);
    $tamaño = $archivo["size"];
    $tipo = $archivo["type"];
    
    // Validar tamaño (máximo 2MB)
    if ($tamaño > 2 * 1024 * 1024) {
        die("El archivo es demasiado grande");
    }
    
    // Validar extensión
    $extension = strtolower(pathinfo($nombreOriginal, PATHINFO_EXTENSION));
    $permitidas = ["jpg", "jpeg", "png", "gif"];
    
    if (!in_array($extension, $permitidas)) {
        die("Solo se permiten imágenes JPG, PNG o GIF");
    }
    
    // Generar nombre único
    $nuevoNombre = uniqid() . "." . $extension;
    $destino = "uploads/" . $nuevoNombre;
    
    // Mover archivo
    if (move_uploaded_file($nombreTemp, $destino)) {
        echo "Archivo subido: $destino";
    } else {
        echo "Error al mover el archivo";
    }
}
?>

19.3 — Códigos de error de subida

CódigoSignificado
UPLOAD_ERR_OKSin error
UPLOAD_ERR_INI_SIZEExcede el límite de php.ini
UPLOAD_ERR_FORM_SIZEExcede el límite del formulario
UPLOAD_ERR_NO_FILENo se subió archivo

Capítulo 20 — Programación Orientada a Objetos

20.1 — Clase básica

<?php
class Persona {
    // Propiedades
    public $nombre;
    public $edad;
    
    // Constructor
    public function __construct($nombre, $edad) {
        $this->nombre = $nombre;
        $this->edad = $edad;
    }
    
    // Método
    public function saludar() {
        return "Hola, soy $this->nombre";
    }
}

// Crear objeto
$ana = new Persona("Ana", 25);
echo $ana->saludar(); // Hola, soy Ana
echo $ana->edad;       // 25
?>

20.2 — Los 3 modificadores de acceso

ModificadorAcceso
publicDesde cualquier lado
protectedSolo desde la clase y sus hijas
privateSolo desde la misma clase
<?php
class Cuenta {
    private $saldo = 0;
    
    public function depositar($monto) {
        if ($monto > 0) {
            $this->saldo += $monto;
        }
    }
    
    public function verSaldo() {
        return $this->saldo;
    }
}

$cuenta = new Cuenta();
$cuenta->depositar(100);
echo $cuenta->verSaldo(); // 100
// $cuenta->saldo = 999;  // ❌ Error, es privado
?>

Capítulo 21 — Conexión a MySQL

21.1 — Conectar con PDO (recomendado)

<?php
try {
    $pdo = new PDO(
        "mysql:host=localhost;dbname=mi_web;charset=utf8mb4",
        "root",
        ""
    );
    
    // Configurar errores
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    
    echo "Conectado";
} catch (PDOException $e) {
    die("Error: " . $e->getMessage());
}
?>

21.2 — Conexión con MySQLi

<?php
$conexion = new mysqli("localhost", "root", "", "mi_web");

if ($conexion->connect_error) {
    die("Error: " . $conexion->connect_error);
}
?>
💡 Recomendación: usa PDO. Es más moderno, seguro y compatible con varios motores de base de datos.

21.3 — Consulta simple (SELECT)

<?php
$stmt = $pdo->query("SELECT * FROM usuarios");
$usuarios = $stmt->fetchAll(PDO::FETCH_ASSOC);

foreach ($usuarios as $usuario) {
    echo $usuario["nombre"] . "<br>";
}
?>

Capítulo 22 — CRUD con MySQL

CRUD = Create, Read, Update, Delete. Es lo básico de cualquier app con base de datos.

22.1 — Tabla de ejemplo

CREATE TABLE usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    creado TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

22.2 — Crear (INSERT)

<?php
$sql = "INSERT INTO usuarios (nombre, email) VALUES (?, ?)";
$stmt = $pdo->prepare($sql);
$stmt->execute(["Ana", "ana@ejemplo.com"]);

echo "ID insertado: " . $pdo->lastInsertId();
?>

22.3 — Leer (SELECT)

<?php
$stmt = $pdo->query("SELECT * FROM usuarios ORDER BY creado DESC");
$usuarios = $stmt->fetchAll(PDO::FETCH_ASSOC);

foreach ($usuarios as $u) {
    echo "{$u['id']} - {$u['nombre']} - {$u['email']}<br>";
}
?>

22.4 — Leer uno con condición

<?php
$sql = "SELECT * FROM usuarios WHERE id = ?";
$stmt = $pdo->prepare($sql);
$stmt->execute([5]);
$usuario = $stmt->fetch(PDO::FETCH_ASSOC);

if ($usuario) {
    echo $usuario["nombre"];
} else {
    echo "No encontrado";
}
?>

22.5 — Actualizar (UPDATE)

<?php
$sql = "UPDATE usuarios SET nombre = ? WHERE id = ?";
$stmt = $pdo->prepare($sql);
$stmt->execute(["Ana María", 5]);

echo "Filas afectadas: " . $stmt->rowCount();
?>

22.6 — Eliminar (DELETE)

<?php
$sql = "DELETE FROM usuarios WHERE id = ?";
$stmt = $pdo->prepare($sql);
$stmt->execute([5]);
?>

22.7 — Consultas preparadas (SEGURIDAD)

⚠️ NUNCA hagas esto: 
$sql = "SELECT * FROM usuarios WHERE email = '$email'";
Es vulnerable a inyección SQL. Un usuario malicioso podría borrar toda la base de datos.

Siempre usa consultas preparadas:

<?php
$sql = "SELECT * FROM usuarios WHERE email = ?";
$stmt = $pdo->prepare($sql);
$stmt->execute([$email]);
?>

Capítulo 23 — Seguridad

23.1 — Las 5 reglas de oro

  1. Nunca confíes en datos del usuario. Valida TODO.
  2. Usa consultas preparadas para SQL. Siempre.
  3. Escapa con htmlspecialchars() antes de mostrar.
  4. Hashea contraseñas con password_hash().
  5. Usa HTTPS en producción.

23.2 — Inyección SQL (ejemplo)

// Si el usuario escribe esto en un campo:
' OR '1'='1

// Y tienes:
$sql = "SELECT * FROM usuarios WHERE user = '$user' AND pass = '$pass'";

// La consulta queda:
SELECT * FROM usuarios WHERE user = '' OR '1'='1' AND pass = '...'
// → Acceso sin credenciales válidas
?>

23.3 — XSS (Cross-Site Scripting)

<?php
// Si guardas esto y lo muestras sin escapar:
$comentario = "<script>alert('hack')</script>";

// MAL:
echo $comentario; // Ejecuta el script

// BIEN:
echo htmlspecialchars($comentario);
// Muestra el texto tal cual, sin ejecutar
?>

23.4 — CSRF (Cross-Site Request Forgery)

<?php
// Generar token al mostrar el formulario
session_start();
$_SESSION["csrf"] = bin2hex(random_bytes(32));
?>

<form method="POST">
    <input type="hidden" name="csrf" value="<?= $_SESSION['csrf'] ?>">
    <button>Enviar</button>
</form>

<?php
// Verificar al recibir
if ($_POST["csrf"] !== $_SESSION["csrf"]) {
    die("Token CSRF inválido");
}
?>

Capítulo 24 — Sesiones avanzadas

24.1 — Login completo

<?php
session_start();

// login.php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $email = $_POST["email"] ?? "";
    $password = $_POST["password"] ?? "";
    
    $stmt = $pdo->prepare("SELECT * FROM usuarios WHERE email = ?");
    $stmt->execute([$email]);
    $usuario = $stmt->fetch(PDO::FETCH_ASSOC);
    
    if ($usuario && password_verify($password, $usuario["password_hash"])) {
        $_SESSION["usuario_id"] = $usuario["id"];
        $_SESSION["nombre"] = $usuario["nombre"];
        header("Location: dashboard.php");
        exit;
    } else {
        $error = "Credenciales incorrectas";
    }
}
?>

25.2 — Base de datos

CREATE DATABASE blog;
USE blog;

CREATE TABLE usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    usuario VARCHAR(50) UNIQUE,
    password_hash VARCHAR(255)
);

CREATE TABLE posts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    titulo VARCHAR(200),
    contenido TEXT,
    autor_id INT,
    creado TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (autor_id) REFERENCES usuarios(id)
);

-- Usuario admin (password: admin123)
INSERT INTO usuarios (usuario, password_hash) VALUES 
('admin', '$2y$10$...');

25.3 — config.php

<?php
$host = "localhost";
$db = "blog";
$user = "root";
$pass = "";

try {
    $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass);
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    die("Error de conexión: " . $e->getMessage());
}

session_start();
?>

25.4 — index.php (lista de posts)

<?php
require "config.php";

$stmt = $pdo->query("
    SELECT p.*, u.usuario 
    FROM posts p 
    JOIN usuarios u ON p.autor_id = u.id 
    ORDER BY p.creado DESC
");
$posts = $stmt->fetchAll(PDO::FETCH_ASSOC);
?>

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi Blog</title>
</head>
<body>

    <?php foreach ($posts as $post): ?>
        <article>
            <h2>
                <a href="post.php?id=<?= $post['id'] ?>">
                    <?= htmlspecialchars($post['titulo']) ?>
                </a>
            </h2>
            <p>Por <?= htmlspecialchars($post['usuario']) ?> 
               el <?= $post['creado'] ?></p>
        </article>
        <hr>
    <?php endforeach; ?>
</body>
</html>

25.6 — admin/crear.php (crear post)

<?php
require "../config.php";

if (!isset($_SESSION["usuario_id"])) {
    header("Location: login.php");
    exit;
}

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $titulo = trim($_POST["titulo"] ?? "");
    $contenido = trim($_POST["contenido"] ?? "");
    
    if ($titulo && $contenido) {
        $stmt = $pdo->prepare("
            INSERT INTO posts (titulo, contenido, autor_id) 
            VALUES (?, ?, ?)
        ");
        $stmt->execute([$titulo, $contenido, $_SESSION["usuario_id"]]);
        header("Location: dashboard.php");
        exit;
    }
}
?>

<!DOCTYPE html>
<html>
<body>
    <h1>Nuevo post</h1>
    <form method="POST">
        <input type="text" name="titulo" placeholder="Título" required><br>
        <textarea name="contenido" rows="10" required></textarea><br>
        <button type="submit">Publicar</button>
    </form>
</body>
</html>
