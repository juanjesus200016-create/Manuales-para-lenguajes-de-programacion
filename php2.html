Capítulo 10 — Funciones

10.1 — Función básica

<?php
function saludar() {
    echo "Hola mundo";
}

saludar(); // Llama a la función
?>

10.2 — Función con parámetros

<?php
function saludar($nombre) {
    echo "Hola, $nombre";
}

saludar("Ana");   // Hola, Ana
saludar("Luis");  // Hola, Luis
?>

10.3 — Función con retorno

<?php
function sumar($a, $b) {
    return $a + $b;
}

$resultado = sumar(5, 3);
echo $resultado; // 8
?>

Diferencia: echo muestra, return devuelve el valor para usarlo después.

10.4 — Parámetros por defecto

<?php
function saludar($nombre = "invitado") {
    return "Hola, $nombre";
}

echo saludar();        // Hola, invitado
echo saludar("Ana");   // Hola, Ana
?>

10.5 — Tipado (PHP 7+)

<?php
function sumar(int $a, int $b): int {
    return $a + $b;
}

// Los tipos se validan automáticamente
?>

10.6 — Funciones anónimas (closures)

<?php
$saludo = function($nombre) {
    return "Hola, $nombre";
};

echo $saludo("Ana"); // Hola, Ana
?>

10.7 — Arrow functions (PHP 7.4+)

<?php
$multiplicar = fn($x) => $x * 2;
echo $multiplicar(5); // 10
?>

10.8 — require e include

<?php
// Incluir otro archivo
include 'header.php';   // Si falla: warning
require 'config.php';   // Si falla: error fatal

include_once 'funciones.php'; // Solo una vez
require_once 'db.php';        // Solo una vez
?>
💡 Regla: usa require_once para archivos críticos (config, funciones, clases).

Capítulo 11 — Arrays avanzados

11.1 — Crear arrays

<?php
// Forma moderna
$frutas = ["Manzana", "Pera", "Uva"];

// Forma antigua
$colores = array("rojo", "verde", "azul");

// Asociativo
$persona = [
    "nombre" => "Ana",
    "edad" => 25
];
?>

11.2 — Operaciones básicas

<?php
$frutas = ["Manzana", "Pera"];

// Añadir al final
$frutas[] = "Uva";

// Añadir al inicio
array_unshift($frutas, "Kiwi");

// Quitar último
array_pop($frutas);

// Quitar primero
array_shift($frutas);

// Contar elementos
echo count($frutas); // 3

// Comprobar si existe
if (in_array("Pera", $frutas)) {
    echo "Sí está";
}
?>

11.3 — Funciones útiles

FunciónQué hace
sort()Ordena ascendente
rsort()Ordena descendente
array_reverse()Invierte el orden
array_unique()Elimina duplicados
array_merge()Une dos arrays
array_slice()Extrae una porción
array_keys()Todas las claves
array_values()Todos los valores
array_sum()Suma todos los valores
array_map()Aplica una función a cada elemento
array_filter()Filtra según condición

11.4 — Ejemplo con array_map

<?php
$numeros = [1, 2, 3, 4, 5];

$dobles = array_map(fn($n) => $n * 2, $numeros);
print_r($dobles); // [2, 4, 6, 8, 10]
?>

11.5 — Ejemplo con array_filter

<?php
$numeros = [1, 2, 3, 4, 5, 6];

$pares = array_filter($numeros, fn($n) => $n % 2 === 0);
print_r($pares); // [2, 4, 6]
?>

11.6 — Arrays multidimensionales

<?php
$alumnos = [
    ["nombre" => "Ana", "nota" => 9],
    ["nombre" => "Luis", "nota" => 7],
    ["nombre" => "Sofía", "nota" => 10]
];

foreach ($alumnos as $alumno) {
    echo $alumno["nombre"] . ": " . $alumno["nota"] . "<br>";
}
?>

11.7 — print_r y var_dump

<?php
$array = [1, 2, ["a", "b"]];

print_r($array);   // Más legible
var_dump($array);  // Más detallado (con tipos)

// Para ver bonito en navegador:
echo "<pre>";
print_r($array);
echo "</pre>";
?>

Capítulo 12 — Funciones de strings

12.1 — Longitud y conversión

<?php
$texto = "Hola Mundo";

strlen($texto);            // 10
strtoupper($texto);        // "HOLA MUNDO"
strtolower($texto);        // "hola mundo"
ucfirst("hola");           // "Hola"
ucwords("hola mundo");     // "Hola Mundo"
?>

12.2 — Buscar y reemplazar

<?php
$texto = "Hola Mundo";

strpos($texto, "Mundo");     // 5 (posición)
str_contains($texto, "Mundo"); // true (PHP 8+)
str_replace("Mundo", "PHP", $texto); // "Hola PHP"
?>

12.3 — Cortar y dividir

<?php
$texto = "Hola Mundo";

substr($texto, 0, 4);       // "Hola"
substr($texto, 5);          // "Mundo"

$csv = "manzana,pera,uva";
$frutas = explode(",", $csv); // ["manzana", "pera", "uva"]

$unido = implode(" - ", $frutas); // "manzana - pera - uva"
?>

12.4 — Limpiar espacios

<?php
$texto = "   Hola   ";
trim($texto);   // "Hola"
ltrim($texto);  // "Hola   " (izquierda)
rtrim($texto);  // "   Hola" (derecha)
?>

12.5 — Formato de números

<?php
$precio = 1234.5678;

number_format($precio, 2);       // "1,234.57"
number_format($precio, 2, ",", "."); // "1.234,57" (formato español)
?>

12.6 — Escapar HTML

<?php
$comentario = "<script>alert('hack')</script>";

htmlspecialchars($comentario);
// "&lt;script&gt;alert('hack')&lt;/script&gt;"
?>
⚠️ IMPORTANTE: usa htmlspecialchars() SIEMPRE que muestres datos del usuario. Evita ataques XSS.

12.7 — Contraseñas seguras

<?php
$password = "miClave123";

// Guardar (nunca en texto plano)
$hash = password_hash($password, PASSWORD_DEFAULT);
// "$2y$10$..." (cadena larga)

// Verificar
if (password_verify("miClave123", $hash)) {
    echo "Contraseña correcta";
}
?>

Capítulo 13 — Formularios GET y POST

13.1 — Formulario HTML básico

<form action="procesar.php" method="POST">
    <label>Nombre: <input type="text" name="nombre"></label>
    <label>Email: <input type="email" name="email"></label>
    <button type="submit">Enviar</button>
</form>

13.2 — Recibir con POST

<?php
// procesar.php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $nombre = $_POST["nombre"] ?? "";
    $email = $_POST["email"] ?? "";
    
    echo "Hola, $nombre. Tu email es: $email";
}
?>

13.3 — Recibir con GET

<?php
// URL: pagina.php?nombre=Ana&edad=25
$nombre = $_GET["nombre"] ?? "";
$edad = $_GET["edad"] ?? 0;
?>

13.5 — Comprobar si se envió

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // Se envió el formulario
}
?>

13.6 — Ejemplo completo: formulario de contacto

<?php
$mensajeExito = "";
$error = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $nombre = trim($_POST["nombre"] ?? "");
    $email = trim($_POST["email"] ?? "");
    $mensaje = trim($_POST["mensaje"] ?? "");
    
    if (empty($nombre) || empty($email) || empty($mensaje)) {
        $error = "Todos los campos son obligatorios";
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $error = "Email no válido";
    } else {
        $mensajeExito = "¡Gracias, $nombre! Te contactaremos pronto.";
    }
}
?>

<!DOCTYPE html>
<html>
<body>
    <?php if ($error): ?>
        <p style="color:red"><?= $error ?></p>
    <?php endif; ?>
    
    <?php if ($mensajeExito): ?>
        <p style="color:green"><?= $mensajeExito ?></p>
    <?php endif; ?>
    
    <form method="POST">
        <input type="text" name="nombre" placeholder="Nombre">
        <input type="email" name="email" placeholder="Email">
        <textarea name="mensaje"></textarea>
        <button type="submit">Enviar</button>
    </form>
</body>
</html>
💡 Atajo: <?= $variable ?> es lo mismo que <?php echo $variable; ?>.

Capítulo 14 — Validación de datos

14.1 — Funciones de validación

<?php
$email = "test@ejemplo.com";

// Validar email
if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "Email válido";
}

// Validar URL
$url = "https://google.com";
if (filter_var($url, FILTER_VALIDATE_URL)) {
    echo "URL válida";
}

// Validar entero
$numero = "42";
if (filter_var($numero, FILTER_VALIDATE_INT)) {
    echo "Es entero";
}
?>

14.2 — Comprobaciones útiles

<?php
$nombre = "Ana";

// ¿Está vacío?
empty($nombre);      // false
isset($nombre);      // true (existe y no es null)

// ¿Es número?
is_numeric("123");   // true
is_numeric("abc");   // false

// ¿Está entre valores?
$edad = 25;
if ($edad >= 18 && $edad <= 65) {
    echo "Edad válida";
}
?>

14.3 — Sanitizar datos

<?php
$nombre = "<script>alert(1)</script>Ana";

// Limpiar HTML
$limpio = htmlspecialchars($nombre);

// O eliminar etiquetas
$sinEtiquetas = strip_tags($nombre);

// Quitar espacios extremos
$limpio = trim($nombre);
?>

14.4 — Expresión regular simple

<?php
// Validar teléfono (10 dígitos)
$telefono = "5512345678";

if (preg_match("/^[0-9]{10}$/", $telefono)) {
    echo "Teléfono válido";
}
?>

Capítulo 15 — Fechas y horas

15.1 — Mostrar la fecha actual

<?php
echo date("d/m/Y");       // 15/10/2026
echo date("Y-m-d");       // 2026-10-15
echo date("H:i:s");       // 14:30:00
echo date("d/m/Y H:i");   // 15/10/2026 14:30

// Día de la semana en español
setlocale(LC_TIME, "es_ES");
?>

15.2 — Códigos de formato

CódigoSignificadoEjemplo

mMes (2 dígitos)01-12
YAño (4 dígitos)2026

15.3 — Timestamp (marca de tiempo)

<?php
$ahora = time(); // Segundos desde 1970
echo $ahora;     // 1760000000 aprox

// Sumar 1 día
$manana = time() + (24 * 60 * 60);
echo date("d/m/Y", $manana);
?>

15.4 — Calcular diferencia entre fechas

<?php
$fecha1 = new DateTime("2026-01-01");
$fecha2 = new DateTime("2026-12-31");

$diferencia = $fecha1->diff($fecha2);
echo $diferencia->days . " días";
?>

15.5 — Crear fecha personalizada

<?php
$fecha = mktime(12, 30, 0, 10, 15, 2026);
// Hora, min, seg, mes, día, año
echo date("Y-m-d H:i", $fecha); // 2026-10-15 12:30
?>

Capítulo 16 — Superglobales

PHP tiene variables especiales que están disponibles en cualquier parte del código.

16.1 — Las 9 superglobales

VariableContiene
$_GETDatos enviados por URL
$_POSTDatos enviados por formulario POST
$_REQUESTCombina GET, POST y COOKIE
$_SERVERInfo del servidor y petición
$_SESSIONDatos de sesión del usuario
$_COOKIECookies del navegador
$_FILESArchivos subidos
$_ENVVariables de entorno
$GLOBALSTodas las variables globales

16.2 — $_SERVER útil

<?php
$_SERVER["REQUEST_METHOD"];  // GET, POST
$_SERVER["PHP_SELF"];        // Ruta del script
$_SERVER["HTTP_USER_AGENT"]; // Navegador del usuario
$_SERVER["REMOTE_ADDR"];     // IP del visitante
$_SERVER["HTTP_HOST"];       // Dominio
?>

16.3 — Variables de sesión (login básico)

<?php
// Iniciar sesión (SIEMPRE al inicio del script)
session_start();

// Guardar datos
$_SESSION["usuario_id"] = 123;
$_SESSION["nombre"] = "Ana";

// Leer
if (isset($_SESSION["usuario_id"])) {
    echo "Bienvenido, " . $_SESSION["nombre"];
}

// Cerrar sesión
session_destroy();
?>
⚠️ Orden importa: session_start() debe ir antes de cualquier HTML o echo.

Capítulo 17 — Ejercicios

Nivel 1 — Básico

  1. Crea una función que reciba dos números y devuelva su multiplicación.
  2. Crea un array con 5 nombres y muéstralos ordenados alfabéticamente.
  3. Pide un nombre por URL con ?nombre=Ana y muéstralo.

Nivel 2 — Intermedio

  1. Crea un formulario HTML con nombre y email. Valídalos en PHP y muestra un mensaje de éxito o error.
  2. Crea una función que cuente cuántas vocales tiene un texto.
  3. Muestra la fecha actual en formato "Miércoles, 15 de Octubre de 2026".

Nivel 3 — Avanzado

  1. Crea una mini calculadora: formulario con dos números y una operación (suma, resta, etc.), procesa en PHP.
  2. Simula un login: si el usuario y contraseña coinciden con datos fijos, guarda sesión y muestra "Bienvenido". Si no, muestra error.
  3. Dado un array de personas (nombre, edad), filtra solo los mayores de edad usando array_filter.
