Capítulo 1 — ¿Qué es PHP?

PHP significa PHP: Hypertext Preprocessor (sí, es recursivo). Es un lenguaje de scripting del lado del servidor creado en 1994 por Rasmus Lerdorf.

1.1 — ¿Qué significa "del lado del servidor"?

Lado cliente (navegador)Lado servidor
Qué esLo que ve el usuarioLo que procesa el servidor
LenguajesHTML, CSS, JavaScriptPHP, Python, Node.js, Ruby
El usuario puede ver el códigoSí (Ver código fuente)No, nunca
Se ejecutaEn el navegadorEn el servidor antes de enviar

1.2 — ¿Qué se puede hacer con PHP?

  • Formularios: recibir y procesar datos del usuario
  • Bases de datos: leer y escribir en MySQL
  • Sesiones: mantener al usuario "logueado"
  • Archivos: subir, leer, escribir
  • APIs: devolver JSON a apps móviles
  • Correos: enviar emails automáticos

1.3 — Sitios famosos hechos con PHP

  • Facebook (originalmente)
  • Wikipedia
  • WordPress (el 43% de internet)
  • Slack, Mailchimp, Tumblr
🧠 Comparación con HTML: HTML es estático. PHP es dinámico. La misma página PHP puede mostrar cosas distintas según quién entre, qué hora sea, o qué haya en la base de datos.

Capítulo 2 — Instalación y entorno

2.1 — La realidad del móvil

PHP NO se ejecuta en el navegador. Necesita un servidor web (Apache, Nginx) con PHP instalado. En el móvil con Spck Code esto es limitado.

2.2 — Opciones para practicar PHP

💡 Recomendación: cuando tengas acceso a PC, instala XAMPP. Es lo más simple. Mientras tanto, estudia la sintaxis con este manual y prueba cuando puedas.

2.3 — Tu primer archivo PHP

<?php
echo "Hola mundo";
?>

Guardado como index.php y accediendo desde http://localhost/index.php, verás "Hola mundo".

⚠️ Aviso: si abres un archivo .php con doble clic (sin servidor), el navegador te mostrará el código o lo descargará. PHP requiere servidor.

Capítulo 3 — Sintaxis básica

3.1 — Etiquetas PHP

<?php
    // Tu código aquí
?>

Todo lo que esté fuera de <?php ... ?> se envía como HTML normal.

3.2 — Mezclar PHP con HTML

<!DOCTYPE html>
<html>
<body>
    <h1>Bienvenido</h1>
    <?php
        echo "<p>Hoy es " . date("d/m/Y") . "</p>";
    ?>
</body>
</html>

3.3 — Terminar instrucciones

<?php
echo "Hola";
echo "Mundo";
?>

Cada instrucción termina en ; obligatoriamente.

3.4 — Comentarios

<?php
// Comentario de una línea
# También de una línea
/* Comentario
   de varias líneas */
?>

3.5 — Mostrar en pantalla: echo y print

<?php
echo "Hola";
echo "Hola", " ", "Mundo"; // Múltiples valores
print "Hola"; // Solo un valor, devuelve 1

// Diferencia:
echo "a", "b"; // ✅ Válido
print "a", "b"; // ❌ Error
?>
💡 Usa echo en el 99% de los casos. print es más lento y menos flexible.

Capítulo 4 — Variables y constantes

4.1 — Variables

<?php
$nombre = "Ana";
$edad = 25;
$altura = 1.65;
$activo = true;
?>
  • Siempre empiezan con $
  • No necesitan declarar tipo (PHP lo detecta)
  • Sensibles a mayúsculas: $nombre ≠ $Nombre
  • Deben empezar con letra o _, no con número

4.2 — Interpolar variables en strings

<?php
$nombre = "Ana";

// Comillas dobles: interpreta variables
echo "Hola, $nombre"; // Hola, Ana
echo "Hola, {$nombre}!"; // Hola, Ana! (más seguro)

// Comillas simples: NO interpreta
echo 'Hola, $nombre'; // Hola, $nombre
?>
🧠 Regla: comillas dobles = variables se procesan. Comillas simples = todo literal.

4.3 — Constantes

<?php
define("PI", 3.14159);
echo PI; // Sin $ al mostrar

// Otra forma (PHP 7+):
const IVA = 0.16;
echo IVA;
?>

Las constantes no se pueden cambiar después de definirlas.

4.4 — Variables variables (curiosidad)

<?php
$nombre = "Ana";
$$nombre = "Valor"; // Crea $Ana = "Valor"
echo $Ana; // Valor
?>

Rara vez se usa, pero existe.

5.2 — Saber el tipo de una variable

<?php
$numero = 42;
$texto = "Hola";

var_dump($numero); // int(42)
var_dump($texto);  // string(4) "Hola"

gettype($numero); // "integer"

is_int($numero);     // true
is_string($texto);   // true
is_array($numero);   // false
?>

5.3 — Conversión de tipos (casting)

<?php
$numero = "42";           // string
$entero = (int) $numero;   // int 42
$decimal = (float) $numero;// float 42.0
$texto = (string) 42;      // string "42"
$booleano = (bool) 0;      // false
?>

5.4 — Arrays básicos

<?php
// Array indexado
$frutas = ["Manzana", "Pera", "Uva"];
echo $frutas[0]; // Manzana

// Array asociativo (como diccionario)
$persona = [
    "nombre" => "Ana",
    "edad" => 25,
    "ciudad" => "CDMX"
];
echo $persona["nombre"]; // Ana
?>

Capítulo 6 — Operadores

6.1 — Aritméticos

<?php
$a = 10;
$b = 3;

echo $a + $b; // 13
echo $a - $b; // 7
echo $a * $b; // 30
echo $a / $b; // 3.3333...
echo $a % $b; // 1 (módulo, resto)
echo $a ** $b;// 1000 (10^3)
?>

6.2 — Comparación

OperadorSignificadoEjemplo
==Igual valor5 == "5" → true
===Igual valor Y tipo5 === "5" → false
!=Distinto valor—
!==Distinto valor o tipo—
< >Menor/mayor—
<= >=Menor/mayor o igual—
<=>Comparación 3 víasDevuelve -1, 0 o 1
⚠️ MUY IMPORTANTE: usa === siempre que puedas. == hace conversiones raras que causan bugs.

6.3 — Lógicos

<?php
$a = true;
$b = false;

$a && $b;  // AND: false
$a || $b;  // OR: true
!$a;       // NOT: false

$a and $b; // Igual que &&
$a or $b;  // Igual que ||
?>

6.4 — Asignación compuesta

<?php
$x = 10;
$x += 5;  // $x = $x + 5 → 15
$x -= 3;  // $x = 12
$x *= 2;  // $x = 24
$x /= 4;  // $x = 6
$x++;     // $x = 7
$x--;     // $x = 6
?>

6.5 — Concatenación de strings

<?php
$nombre = "Ana";
$saludo = "Hola, " . $nombre . "!"; // Con punto
echo $saludo; // Hola, Ana!

// Con .= acumulativo
$texto = "Hola";
$texto .= " mundo"; // "Hola mundo"
?>

Capítulo 7 — Condicionales

7.1 — if simple

<?php
$edad = 18;

if ($edad >= 18) {
    echo "Eres mayor de edad";
}
?>

7.2 — if / else

<?php
$edad = 15;

if ($edad >= 18) {
    echo "Mayor de edad";
} else {
    echo "Menor de edad";
}
?>

7.3 — elseif (varias condiciones)

<?php
$nota = 85;

if ($nota >= 90) {
    echo "Excelente";
} elseif ($nota >= 80) {
    echo "Muy bien";
} elseif ($nota >= 70) {
    echo "Bien";
} elseif ($nota >= 60) {
    echo "Aprobado";
} else {
    echo "Reprobado";
}
?>

7.4 — Operador ternario

<?php
$edad = 20;
$mensaje = ($edad >= 18) ? "Mayor" : "Menor";
echo $mensaje;
?>

7.5 — switch

<?php
$dia = "lunes";

switch ($dia) {
    case "lunes":
    case "martes":
        echo "Inicio de semana";
        break;
    case "miercoles":
        echo "Mitad de semana";
        break;
    case "viernes":
        echo "¡Por fin!";
        break;
    default:
        echo "Otro día";
}
?>

7.6 — match (PHP 8+)

<?php
$codigo = 200;

$mensaje = match ($codigo) {
    200 => "OK",
    404 => "No encontrado",
    500 => "Error servidor",
    default => "Desconocido"
};
echo $mensaje;
?>

match es más estricto que switch (usa ===).

Capítulo 8 — Bucles

8.1 — for

<?php
for ($i = 0; $i < 5; $i++) {
    echo "Número: $i <br>";
}
// Imprime 0, 1, 2, 3, 4
?>

8.2 — while

<?php
$i = 0;
while ($i < 5) {
    echo "Valor: $i <br>";
    $i++;
}
?>

8.3 — do...while

<?php
$i = 0;
do {
    echo "Valor: $i <br>";
    $i++;
} while ($i < 5);
?>

Diferencia: do...while ejecuta al menos una vez, aunque la condición sea falsa desde el inicio.

8.4 — foreach (para arrays)

<?php
$frutas = ["Manzana", "Pera", "Uva"];

foreach ($frutas as $fruta) {
    echo "$fruta <br>";
}

// Con índice
foreach ($frutas as $indice => $fruta) {
    echo "$indice: $fruta <br>";
}
?>

8.5 — foreach en arrays asociativos

<?php
$persona = [
    "nombre" => "Ana",
    "edad" => 25,
    "ciudad" => "CDMX"
];

foreach ($persona as $clave => $valor) {
    echo "$clave: $valor <br>";
}
?>

8.6 — break y continue

<?php
for ($i = 0; $i < 10; $i++) {
    if ($i == 3) continue; // Salta el 3
    if ($i == 7) break;    // Se detiene en el 7
    echo "$i <br>";
}
// Imprime 0, 1, 2, 4, 5, 6
?>

Capítulo 9 — Ejercicios

Nivel 1 — Básico

  1. Crea una variable $nombre con tu nombre y muéstrala en un echo.
  2. Crea dos números y muestra su suma, resta, multiplicación y división.
  3. Usa un if para decir si un número es par o impar (pista: usa %).

Nivel 2 — Intermedio

  1. Crea un array con 5 frutas y muéstralas con foreach.
  2. Haz una tabla HTML con PHP que muestre los números del 1 al 10 y su cuadrado.
  3. Crea un switch que según el día de la semana diga si es laboral o fin de semana.

Nivel 3 — Avanzado

  1. Crea un array asociativo con 3 personas (nombre, edad) y muéstralas en una tabla.
  2. Haz un bucle que genere la tabla de multiplicar del 1 al 10.
  3. Combina if con foreach: dado un array de números, muestra solo los pares.
