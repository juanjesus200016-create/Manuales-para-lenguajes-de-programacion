Capítulo 10 — Flexbox

Flexbox es el sistema para distribuir elementos en fila o columna. Revolucionó el diseño web.

10.1 — Activar Flexbox

.contenedor { display: flex; }

Todos los hijos directos se convierten en "items flexibles".

10.2 — Dirección: flex-direction

ValorEfecto
rowHorizontal (por defecto)
columnVertical
row-reverseHorizontal inverso
column-reverseVertical inverso

10.3 — Alineación horizontal: justify-content

ValorEfecto
flex-startAl inicio
centerCentrado
flex-endAl final
space-betweenExtremos pegados, espacio entre items
space-aroundEspacio alrededor de cada item
space-evenlyEspacio igual entre todos

10.4 — Alineación vertical: align-items

ValorEfecto
stretchEstirados (por defecto)
flex-startArriba
centerCentro
flex-endAbajo

10.5 — Centrar perfectamente un elemento

.contenedor {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
}

10.6 — Salto de línea: flex-wrap

.contenedor { display: flex; flex-wrap: wrap; }
  • nowrap (por defecto): todo en una línea
  • wrap: salta a siguiente línea si no cabe

10.7 — Espacio entre items: gap

.contenedor { display: flex; gap: 20px; }

Más limpio que usar margins individuales.

10.8 — Propiedades de los items

.item {
    flex-grow: 1;
    flex-shrink: 0;
    flex-basis: 200px;
}
/* Atajo */
.item { flex: 1 0 200px; }

Capítulo 11 — Grid

CSS Grid es el sistema para cuadrículas bidimensionales (filas Y columnas a la vez).

11.1 — Activar Grid

.contenedor {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    grid-template-rows: 100px 100px;
    gap: 20px;
}

11.2 — Unidad fr (fracción)

grid-template-columns: 1fr 2fr 1fr;

1fr 2fr 1fr = 25% 50% 25% del espacio.

11.3 — Repetir columnas

grid-template-columns: repeat(3, 1fr);

11.4 — Grid responsive automático

grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

Columnas que se adaptan: mínimo 250px, máximo todo el espacio.

11.5 — Ubicar items

.item {
    grid-column: 1 / 3;
    grid-row: 1 / 2;
}
/* Con span */
.item {
    grid-column: span 2;
    grid-row: span 3;
}

11.6 — Áreas nombradas

.contenedor {
    display: grid;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
    grid-template-columns: 200px 1fr;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

Capítulo 12 — Pseudo-clases y pseudo-elementos

12.1 — Pseudo-clases

Pseudo-claseCuándo se aplica
:hoverAl pasar el ratón
:activeAl hacer clic
:focusAl enfocar (input activo)
:visitedEnlace ya visitado
:first-childPrimer hijo
:last-childÚltimo hijo
:nth-child(n)Hijo número n
:nth-child(odd)Filas impares
:nth-child(even)Filas pares
:not(selector)Que NO cumpla algo
a:hover { color: red; }
input:focus { border-color: blue; }
tr:nth-child(even) { background: #f5f5f5; }
li:not(.activo) { opacity: 0.5; }

12.2 — Pseudo-elementos

Pseudo-elementoFunción
::beforeContenido antes
::afterContenido después
::first-letterPrimera letra
::first-linePrimera línea
::selectionTexto seleccionado
.precio::after { content: " €"; color: green; }
p::first-letter { font-size: 3em; font-weight: bold; }
::selection { background: yellow; color: black; }
💡 ::before y ::after necesitan content: ""; aunque sea vacío.

Capítulo 13 — Transiciones y animaciones

13.1 — Transiciones

.boton {
    background: blue;
    transition: background 0.3s ease;
}
.boton:hover { background: red; }

Curvas de aceleración

  • ease — suave (por defecto)
  • linear — velocidad constante
  • ease-in — empieza lento
  • ease-out — termina lento
  • ease-in-out — lento en ambos extremos

Múltiples propiedades

.caja {
    transition: background 0.3s ease, transform 0.5s ease-in-out;
}

13.2 — Transformaciones

.caja:hover {
    transform: scale(1.1);
    transform: rotate(45deg);
    transform: translate(20px, 10px);
    transform: skew(10deg);
}
/* Combinar */
transform: translate(-50%, -50%) scale(1.2) rotate(10deg);

13.3 — Animaciones con @keyframes

@keyframes rebote {
    0%   { transform: translateY(0); }
    50%  { transform: translateY(-30px); }
    100% { transform: translateY(0); }
}
.pelota {
    animation: rebote 1s infinite;
}
PropiedadFunción
animation-nameNombre del keyframe
animation-durationDuración
animation-iteration-countRepeticiones
animation-delayRetraso
animation-directionnormal / reverse / alternate
animation-fill-modeEstado final (forwards)
