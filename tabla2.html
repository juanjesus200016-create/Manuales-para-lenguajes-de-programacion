1.3 — Cómo se escribe en CSS

Qué Cómo se escribe Qué hace Dónde se coloca
Una fuente font-family: Arial; Aplica Arial Dentro de selector
Varias con fallback font-family: 'Segoe UI', Arial, sans-serif; Prueba en orden hasta que una funcione Dentro de selector
Fuente con espacios font-family: 'Times New Roman'; Comillas obligatorias Dentro de selector
Tamaño font-size: 16px; Define tamaño (px, rem, em) Dentro de selector
Peso font-weight: bold; Negrita (100-900 o normal/bold) Dentro de selector
Estilo font-style: italic; Cursiva (normal/italic/oblique) Dentro de selector
Interlineado line-height: 1.6; Espacio entre líneas Dentro de selector
Espacio letras letter-spacing: 1px; Separación entre letras Dentro de selector

1.4 — Google Fonts (requiere internet)

Qué Cómo se escribe Qué hace Dónde se coloca
Importar <link href="https://fonts.googleapis.com/css2?family=Roboto" rel="stylesheet"> Descarga la fuente Dentro de head
Usar font-family: 'Roboto', sans-serif; Aplica la fuente descargada Dentro de selector

2. Colores

2.1 — Formas de escribir colores

Formato Cómo se escribe Ejemplo visual Cuándo usar
Nombre color: red; red Prototipos rápidos
HEX 6 dígitos color: #ff0000; #ff0000 Uso general web
HEX 3 dígitos color: #f00; #f00 Abreviar cuando coinciden
RGB color: rgb(255, 0, 0); rgb(255,0,0) Cuando calculas valores
RGBA (transparencia) color: rgba(255, 0, 0, 0.5); 50% opaco Transparencias
HSL color: hsl(0, 100%, 50%); hsl(0,100%,50%) Ajustar tono/saturación
HSLA color: hsla(0, 100%, 50%, 0.5); 50% Transparencia + tono

7.3 — Meta tags útiles

Qué Cómo se escribe Qué hace
Charset <meta charset="UTF-8"> Acentos y ñ correctos
Viewport <meta name="viewport" content="width=device-width, initial-scale=1.0"> Diseño responsive en móvil
Descripción <meta name="description" content="..."> SEO: texto en Google
Keywords <meta name="keywords" content="html,css"> Obsoleto, no usar
Author <meta name="author" content="Tu nombre"> Autor del sitio
Theme color <meta name="theme-color" content="#3498db"> Color de la barra en móvil
Open Graph <meta property="og:title" content="..."> Vista previa en redes sociales
