Capítulo 1 — ¿Qué es CSS?

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada). Es el lenguaje que da vida visual a HTML.

1.1 — Los 3 pilares (recordatorio)

LenguajeRol
HTMLEstructura (qué es cada cosa)
CSSDiseño (cómo se ve)
JavaScriptComportamiento (qué hace)

1.2 — ¿Por qué se llama "en cascada"?

Porque los estilos se aplican en cascada: si hay varias reglas para el mismo elemento, se aplican por prioridad:

  1. Estilos del navegador (por defecto)
  2. Estilos externos (archivo .css)
  3. Estilos internos (dentro del <style>)
  4. Estilos en línea (atributo style)
  5. Estilos con !important

1.3 — Analogía con VBS

En VBS escribías Range("A1").Font.Bold = True para poner negrita. En CSS sería:

#A1 { font-weight: bold; }

Es la misma idea: seleccionar un elemento y darle propiedades.

Capítulo 2 — Formas de aplicar CSS

2.1 — CSS en línea (inline)

<p style="color: red; font-size: 20px;">Texto rojo</p>
  • Ventaja: rápido de probar.
  • Desventaja: no se reutiliza, difícil de mantener.
  • Uso: solo para casos muy específicos.

2.2 — CSS interno (en el <head>)

<head>
    <style>
        p { color: red; }
        h1 { font-size: 32px; }
    </style>
</head>
  • Ventaja: aplica a toda la página.
  • Desventaja: solo funciona para esa página.

2.3 — CSS externo (archivo .css) ✅ RECOMENDADO

<head>
    <link rel="stylesheet" href="estilos.css">
</head>

Y en el archivo estilos.css:

p {
    color: red;
    font-size: 16px;
}
h1 {
    color: blue;
}
  • Ventaja: un archivo sirve para muchas páginas.
  • Ventaja: el navegador lo guarda en caché (más rápido).
  • Uso: siempre que puedas.

2.4 — Importar otro CSS desde CSS

@import url("otro-estilos.css");

Menos eficiente que <link>, evítalo salvo casos concretos.

Capítulo 3 — Sintaxis y selectores

3.1 — Anatomía de una regla CSS

selector {
    propiedad: valor;
    otra-propiedad: otro-valor;
}

Ejemplo:

h1 {
    color: blue;
    font-size: 32px;
}
ParteFunción
h1Selector: a quién afecta
{ }Bloque de estilos
colorPropiedad
blueValor
;Separa declaraciones (obligatorio)

3.2 — Tipos de selectores

🔹 Selector de etiqueta

p { color: gray; }

Afecta a todos los <p>.

🔹 Selector de clase (.)

.destacado { background: yellow; }
<p class="destacado">Texto resaltado</p>

Afecta a todos los elementos con class="destacado". Se puede repetir.

🔹 Selector de ID (#)

#titulo-principal { font-size: 40px; }
<h1 id="titulo-principal">Título</h1>

Afecta a un solo elemento. Debe ser único por página.

🔹 Selector universal (*)

* { margin: 0; padding: 0; }

Afecta a TODO. Muy útil para resetear estilos.

🔹 Selector descendiente (espacio)

article p { color: gray; }

Afecta a los <p> que estén DENTRO de un <article>.

🔹 Selector hijo directo (>)

ul > li { color: blue; }

Solo los <li> que sean hijos directos de <ul>.

🔹 Selector hermano adyacente (+)

h1 + p { margin-top: 0; }

El <p> que viene justo después de un <h1>.

🔹 Selector de atributo

input[type="text"] { border: 1px solid gray; }
a[target="_blank"] { color: red; }

🔹 Agrupar selectores (,)

h1, h2, h3 { font-family: Arial; }

Aplica los mismos estilos a varios selectores.

3.3 — Prioridad (especificidad)

Cuando hay conflicto, gana el más específico:

  1. !important (evitar usar)
  2. Estilos en línea (style="...")
  3. ID (#id)
  4. Clase (.clase)
  5. Etiqueta (p)
⚠️ Regla de oro: evita usar !important. Es la señal de que algo está mal estructurado.

Capítulo 4 — Colores y unidades

4.1 — Formas de escribir colores

🔹 Nombres predefinidos

color: red;
color: blue;
color: tomato;
color: coral;

Hay ~140 nombres disponibles. Limitado.

🔹 Hexadecimal (HEX)

color: #ff0000;    /* rojo */
color: #00ff00;    /* verde */
color: #0000ff;    /* azul */
color: #333333;    /* gris oscuro */
color: #fff;       /* blanco (abreviado) */

Formato: #RRGGBB (rojo, verde, azul en hexadecimal 00-ff).

🔹 RGB / RGBA

color: rgb(255, 0, 0);          /* rojo */
color: rgba(255, 0, 0, 0.5);    /* rojo al 50% transparente */

Rango 0-255 por canal. rgba añade opacidad (0 a 1).

🔹 HSL / HSLA (más intuitivo)

color: hsl(0, 100%, 50%);       /* rojo */
color: hsla(0, 100%, 50%, 0.5); /* rojo 50% */
  • H (Hue): tono 0-360 (0 rojo, 120 verde, 240 azul)
  • S (Saturation): saturación 0-100%
  • L (Lightness): luminosidad 0-100%
💡 Recomendación: usa HEX para diseños rápidos, HSL cuando quieras variaciones del mismo color.

4.2 — Unidades de medida

Unidades absolutas

UnidadEquivalencia
pxPíxel (unidad base)
pt1pt = 1.333px (para impresión)
cmCentímetro
inPulgada

Unidades relativas (recomendadas)

UnidadRelativa aUso típico

emTamaño de fuente del padreTexto, márgenes

🧠 Diferencia clave: em depende del padre, rem siempre del <html>. Usa rem para evitar sorpresas.

Capítulo 5 — Texto y tipografía

5.1 — Fuente

body {
    font-family: 'Segoe UI', Arial, sans-serif;
}
  • Siempre terminar con genérica: serif, sans-serif, monospace.
  • Comillas en nombres con espacios.
  • Varias opciones separadas por comas: si una falla, pasa a la siguiente.

5.2 — Tamaño y estilo

p {
    font-size: 16px;
    font-weight: bold;       /* 100-900 o normal/bold */
    font-style: italic;      /* normal / italic / oblique */
    text-transform: uppercase; /* Mayúsculas forzadas */
}

5.3 — Alineación y decoración

p {
    text-align: center;      /* left / right / center / justify */
    text-decoration: underline; /* none / underline / line-through */
    letter-spacing: 1px;     /* Espacio entre letras */
    line-height: 1.6;        /* Alto de línea (sin unidad = proporcional) */
    word-spacing: 2px;       /* Espacio entre palabras */
}

5.4 — Sombra de texto

h1 {
    text-shadow: 2px 2px 4px rgba(0,0,0,0.3);
    /* desplaz-X desplaz-Y desenfoque color */
}

5.5 — Importar fuentes de Google

<head>
    <link href="https://fonts.googleapis.com/css2?family=Roboto" rel="stylesheet">
</head>
body { font-family: 'Roboto', sans-serif; }
⚠️ Ojo: requiere conexión a internet. Si tienes red limitada, usa fuentes del sistema (Arial, Georgia, Courier).

Capítulo 6 — Modelo de caja (Box Model)

El concepto MÁS IMPORTANTE de CSS. Todo elemento es una caja con 4 capas:

┌─────────────────────────────────┐
│           MARGIN                │
│  ┌───────────────────────────┐  │
│  │         BORDER            │  │
│  │  ┌─────────────────────┐  │  │
│  │  │      PADDING        │  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │   CONTENT     │  │  │  │
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘

6.1 — Cada capa explicada

CapaQué esPropiedad CSS
ContentEl contenido real (texto, imagen)width, height
PaddingEspacio interno (entre contenido y borde)padding
BorderBorde visibleborder
MarginEspacio externo (entre este elemento y otros)margin

6.2 — Ejemplo práctico

.caja {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    margin: 30px;
}

El ancho total real es: 200 + 20×2 + 5×2 = 250px (sin contar margin).

6.3 — box-sizing: la solución

* {
    box-sizing: border-box;
}

Con border-box, el width incluye padding y border. El total sigue siendo 200px.

💡 Regla universal: pon siempre * { box-sizing: border-box; } al inicio. Te ahorrará dolores de cabeza.

6.4 — Atajos de margin/padding

/* 4 valores: arriba derecha abajo izquierda */
margin: 10px 20px 30px 40px;

/* 3 valores: arriba, lados, abajo */
margin: 10px 20px 30px;

/* 2 valores: vertical | horizontal */
margin: 10px 20px;

/* 1 valor: todos iguales */
margin: 10px;

6.5 — Centrar horizontalmente

.caja {
    width: 300px;
    margin: 0 auto; /* Truco clásico */
}

6.6 — Colapsado de márgenes

Si dos elementos uno encima del otro tienen margin-bottom: 20px y margin-top: 30px, el espacio resultante es 30px (el mayor), no 50px.

    border-radius: 10px;
}

7.3 — Box-shadow (sombra)

.caja {
    box-shadow: 5px 5px 10px rgba(0,0,0,0.3);
    /* X | Y | desenfoque | color */
}
/* Sombra interna */
box-shadow: inset 0 0 10px rgba(0,0,0,0.2);

/* Múltiples sombras */
box-shadow: 
    0 2px 5px rgba(0,0,0,0.1),
    0 8px 15px rgba(0,0,0,0.1);

Capítulo 8 — Fondos

8.1 — Color de fondo

8.2 — Imagen de fondo

.hero {
    background-image: url('fondo.jpg');
    background-size: cover;       /* Cubre todo el espacio */
    background-position: center;  /* Centrada */
    background-repeat: no-repeat; /* No se repite */
}

Valores de background-size

ValorEfecto

containSe ajusta sin recortar (puede dejar huecos)
100% 100%Estira a lo ancho y alto

Capítulo 9 — Display y posicionamiento

9.1 — La propiedad display

ValorComportamientoEjemplos
blockOcupa todo el ancho, salto de líneadiv, p, h1
inlineSolo su contenido, sin ancho/altospan, a, strong
inline-blockComo inline pero acepta width/height—
noneOculto (no ocupa espacio)—
flexContenedor flexible (cap. 10)—
gridContenedor de cuadrícula (cap. 11)—
⚠️ Diferencia clave: display: none elimina el elemento. visibility: hidden lo oculta pero deja el espacio.

9.2 — La propiedad position

ValorComportamiento
staticPor defecto, sigue el flujo normal
relativeSe mueve respecto a su posición original
absoluteSe posiciona respecto a un ancestro relative
fixedFijo en pantalla, no se mueve al hacer scroll
stickySe comporta como relative hasta llegar a un punto, luego se
Se comporta como relative hasta llegar a un punto, luego se fija

Ejemplo: menú fijo arriba

nav {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    background: white;
    box-shadow: 0 2px 5px rgba(0,0,0,0.1);
}

Ejemplo: elemento centrado en pantalla

.centrado {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}

9.3 — Propiedades top, right, bottom, left

Solo funcionan si position NO es static.

.caja {
    position: absolute;
    top: 20px;
    right: 30px;
}

9.4 — z-index (profundidad)

.modal {
    position: absolute;
    z-index: 1000;
}

Solo funciona con position diferente a static.
