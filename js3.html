Capítulo 19 — ¿Qué es la asincronía?

JavaScript es single-threaded: hace una cosa a la vez. Pero algunas operaciones (pedir datos, esperar) tardan. La asincronía permite que JS no se bloquee esperando.

19.1 — Síncrono vs Asíncrono

SíncronoAsíncrono
EsperaBloquea hasta terminarContinúa con otra cosa
EjemploUna sumaPedir datos a un servidor
VelocidadInmediatoPuede tardar

19.2 — Ejemplo práctico

console.log("1");
console.log("2");

setTimeout(() => {
    console.log("3 (después de 1 segundo)");
}, 1000);

console.log("4");

// Salida: 1, 2, 4, 3

El setTimeout no bloquea. JS sigue ejecutando el resto.

Capítulo 20 — Callbacks

Un callback es una función que se pasa como argumento y se ejecuta después.

function procesar(datos, callback) {
    console.log("Procesando...");
    callback(datos * 2);
}

procesar(5, (resultado) => {
    console.log(`Resultado: ${resultado}`);
});

20.1 — El problema del "callback hell"

obtenerUsuario(1, (usuario) => {
    obtenerPosts(usuario.id, (posts) => {
        obtenerComentarios(posts[0].id, (comentarios) => {
            obtenerAutor(comentarios[0].id, (autor) => {
                console.log(autor);
                // ... y sigue creciendo
            });
        });
    });
});

Esto se llama callback hell. Las promesas lo resuelven.

Capítulo 21 — Promesas

Una promesa es un objeto que representa un valor que estará disponible ahora, en el futuro, o nunca.

21.1 — Estados de una promesa

  • Pending: pendiente (aún no termina)
  • Fulfilled: cumplida (éxito)
  • Rejected: rechazada (error)

21.2 — Crear una promesa

let promesa = new Promise((resolve, reject) => {
    let exito = true;
    
    if (exito) {
        resolve("Todo bien");
    } else {
        reject("Algo falló");
    }
});

21.3 — Consumir una promesa

promesa
    .then(resultado => {
        console.log("Éxito:", resultado);
    })
    .catch(error => {
        console.error("Error:", error);
    })
    .finally(() => {
        console.log("Siempre se ejecuta");
    });

21.4 — Encadenar

obtenerUsuario(1)
    .then(usuario => obtenerPosts(usuario.id))
    .then(posts => obtenerComentarios(posts[0].id))
    .then(comentarios => console.log(comentarios))
    .catch(error => console.error(error));

21.5 — Promise.all (esperar varias)

Promise.all([
    fetch("/api/usuarios"),
    fetch("/api/posts"),
    fetch("/api/comentarios")
])
.then(([usuarios, posts, comentarios]) => {
    console.log("Todo listo");
})
.catch(error => console.error(error));

21.6 — Promise.race

Promise.race([
    fetch("/api/servidor1"),
    fetch("/api/servidor2")
])
.then(respuesta => {
    console.log("El que responda primero");
});

Capítulo 22 — async / await

Sintaxis moderna que hace el código asíncrono parecer síncrono.

22.1 — Sintaxis básica

async function obtenerDatos() {
    let respuesta = await fetch("/api/datos");
    let datos = await respuesta.json();
    return datos;
}

obtenerDatos().then(datos => console.log(datos));

22.2 — Con try/catch

async function obtenerDatos() {
    try {
        let respuesta = await fetch("/api/datos");
        
        if (!respuesta.ok) {
            throw new Error("Error HTTP: " + respuesta.status);
        }
        
        let datos = await respuesta.json();
        return datos;
    } catch (error) {
        console.error("Falló:", error.message);
        return null;
    } finally {
        console.log("Terminó");
    }
}

22.3 — Esperar varias promesas

async function cargarTodo() {
    let [usuarios, posts] = await Promise.all([
        fetch("/api/usuarios").then(r => r.json()),
        fetch("/api/posts").then(r => r.json())
    ]);
    
    console.log(usuarios, posts);
}

22.4 — Múltiples await secuenciales

async function secuencial() {
    let a = await tarea1();
    let b = await tarea2(a); // Usa el resultado de a
    let c = await tarea3(b); // Usa el resultado de b
    return c;
}
💡 Regla moderna: usa async/await en vez de .then(). Es más limpio y fácil de leer.

Capítulo 23 — Fetch API

fetch() es la forma moderna de hacer peticiones HTTP (AJAX) desde JS.

23.1 — GET simple

fetch("https://api.ejemplo.com/usuarios")
    .then(respuesta => respuesta.json())
    .then(datos => console.log(datos))
    .catch(error => console.error(error));

23.2 — Con async/await

async function obtenerUsuarios() {
    let respuesta = await fetch("https://api.ejemplo.com/usuarios");
    let datos = await respuesta.json();
    return datos;
}

23.3 — Comprobar respuesta

let respuesta = await fetch(url);

if (respuesta.ok) {
    let datos = await respuesta.json();
} else {
    console.error("Error:", respuesta.status);
}

// Códigos comunes
respuesta.status;      // 200, 404, 500...
respuesta.statusText;  // "OK", "Not Found"
respuesta.ok;          // true si 200-299

23.4 — POST con datos

async function crearUsuario(usuario) {
    let respuesta = await fetch("/api/usuarios", {
        method: "POST",
        headers: {
            "Content-Type": "application/json"
        },
        body: JSON.stringify(usuario)
    });
    
    return respuesta.json();
}

crearUsuario({ nombre: "Ana", edad: 25 });

23.5 — Métodos HTTP

MétodoUso
GETObtener datos
POSTCrear
PUTActualizar todo
PATCHActualizar parte
DELETEBorrar

23.6 — Ejemplo real: cargar y mostrar

<div id="usuarios"></div>

<script>
async function cargar() {
    let respuesta = await fetch("https://jsonplaceholder.typicode.com/users");
    let usuarios = await respuesta.json();
    
    let html = "";
    usuarios.forEach(u => {
        html += `<div class="usuario">
            <h3>${u.name}</h3>
            <p>${u.email}</p>
        </div>`;
    });
    
    document.querySelector("#usuarios").innerHTML = html;
}

cargar();
</script>

Capítulo 24 — Manejo de errores

24.1 — try / catch / finally

try {
    let resultado = 10 / 0;
    throw new Error("Algo salió mal");
} catch (error) {
    console.error(error.message);
} finally {
    console.log("Siempre se ejecuta");
}

24.2 — Lanzar errores

function dividir(a, b) {
    if (b === 0) {
        throw new Error("No se puede dividir entre cero");
    }
    return a / b;
}

try {
    dividir(10, 0);
} catch (e) {
    console.error(e.message);
}

24.3 — Errores personalizados

class MiError extends Error {
    constructor(mensaje, codigo) {
        super(mensaje);
        this.codigo = codigo;
    }
}

throw new MiError("Usuario no encontrado", 404);

Capítulo 25 — Timers

25.1 — setTimeout (una vez)

setTimeout(() => {
    console.log("Después de 2 segundos");
}, 2000);

// Cancelar
let id = setTimeout(() => console.log("No aparecerá"), 1000);
clearTimeout(id);

25.2 — setInterval (repetido)

let id = setInterval(() => {
    console.log("Cada segundo");
}, 1000);

// Cancelar
clearInterval(id);

25.3 — Reloj simple

setInterval(() => {
    let ahora = new Date();
    document.querySelector("#reloj").textContent =
        ahora.toLocaleTimeString();
}, 1000);

25.4 — Cuenta regresiva

let segundos = 10;
let intervalo = setInterval(() => {
    console.log(segundos);
    segundos--;
    
    if (segundos < 0) {
        clearInterval(intervalo);
        console.log("¡Fin!");
    }
}, 1000);

Capítulo 26 — Progressive Web App (PWA)

Una PWA es una página web que se puede instalar como app y funciona sin internet.

26.1 — Componentes de una PWA

ComponenteFunción
manifest.jsonDatos de la app (nombre, iconos, colores)
sw.js (Service Worker)Cachea archivos, funciona offline
HTTPS o localhostRequisito de seguridad

26.2 — Enlazar en el HTML

<link rel="manifest" href="manifest.json">
<meta name="theme-color" content="#2a5298">

<script>
if ("serviceWorker" in navigator) {
    navigator.serviceWorker.register("sw.js")
        .then(reg => console.log("SW registrado"))
        .catch(err => console.error("Error SW:", err));
}
</script>

26.3 — Estructura del manifest

{
  "name": "Mi App",
  "short_name": "App",
  "start_url": "index.html",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#2a5298",
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}

26.4 — Service Worker básico

const CACHE = "app-v1";
const ARCHIVOS = ["index.html", "style.css", "app.js"];

self.addEventListener("install", (e) => {
    e.waitUntil(
        caches.open(CACHE).then(cache => cache.addAll(ARCHIVOS))
    );
});

self.addEventListener("fetch", (e) => {
    e.respondWith(
        caches.match(e.request).then(resp =>
            resp || fetch(e.request)
        )
    );
});
💡 En Spck Code: si ejecutas tu biblioteca como PWA y registras el Service Worker, podrás usarla sin internet. Pero el registro solo funciona si se sirve por HTTPS o localhost, no siempre desde el preview de Spck.
